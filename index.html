Turns the active body into front, back, side and jump views, plus a 2-frame run cycle. Everything above the hips — head, hair, hats, capes, whatever you've drawn — carries over as a whole. Only the legs and arms actually move, so anything drawn hanging off a hand or foot won't follow it round the bend.

Experimental: an animated run cycle sampled at more points along the same leg/arm swing, instead of just the two stride extremes above.

Experimental: spins the character using only the front/back views you already have — a cosine squash as it turns away from you, swapping to the back past 90°. It doesn't invent a true side silhouette mid-turn (that's a different shape — see the pose sheet's side view), so treat it as a design aid, not an exact render.
