# Characters

Hand-designed bosses and NPCs made in [Sprite Forge](../index.html), imported
from browser downloads and organized here.

- `originals/` — the designed sprites, one file per named variant. See
  `catalog.json` for which files belong to the same character, which variant
  looks most finished, and any notes worth knowing before reusing one.
- `sketches/` — a couple of files that look like abandoned drafts rather than
  a finished character. Kept for reference, not catalogued as designs.
- `originals_contact_sheet.png` — a labelled grid of everything in
  `originals/`, regenerate with `catalog_sheet.py` after adding new files.
